01 / 5 MIN

接线 → Ping → SSH

机器狗 Type-C → 转千兆网口 → 网线 → 电脑网口

电脑有线 IP：192.168.126.100/24，网关/DNS 留空。狗的计算板：192.168.126.2。电脑不要占用 .2。

Windows PowerShell · 只读检查
Get-NetAdapter | Format-Table Name, Status, LinkSpeed
Get-NetIPAddress -AddressFamily IPv4
ping 192.168.126.2
Test-NetConnection 192.168.126.2 -Port 22
电脑终端 / WSL
ssh vbot@192.168.126.2
换狗与 WiFi 备用入口

Host Key 冲突时先确认设备身份并备份旧记录，再接受已核对的新指纹。原电脑旧狗记录位于 ~/.ssh/vbot-backup-20261023-JUyK1a/，其他电脑不一定存在此目录。

WiFi 开发模式通常使用 192.168.127.2，以设备实际配置为准；192.168.127.10 是网关板。

03 / 10 MIN

视觉：先识别人，再谈手势

让参与者站到镜头前。当前默认模型检测人体，输出 person、置信度和像素检测框。

机器狗 SSH · 获取一帧检测
timeout 15s ros2 topic echo /perception/detections2d vision_msgs/msg/Detection2DArray --no-daemon --once --qos-reliability best_effort

验收：找到 class_id: person 与 score。随后让参与者离开画面再采样。空数组表示该帧未检出；超时不能当作无人。

人体姿态采样
机器狗 SSH
timeout 15s ros2 topic echo /perception/poses vision_msgs/msg/PoseDetection --no-daemon --once --qos-reliability best_effort

17 个 COCO 点包括肩、肘、手腕，没有手指关节。关键点 confidence 是 logit，需要转换为 sigmoid 概率。坐标是像素，不是距离；样本也不能确定某个人的身份。

不能用当前人体模型判断“比了几根手指”。这需要额外手部关键点或图像问答链路。
相机 / 检测频率检查
机器狗 SSH
timeout 8s ros2 topic hz /image_left_raw/h265_undistort
timeout 8s ros2 topic hz /perception/detections2d

测频退出 124 是限时结束；看期间是否有实际频率输出。

04 / 10 MIN

语音：开关成功 ≠ 识别成功

先记录原状态。mode 0：关闭；1：本地语音服务；2：云端 ASR。

机器狗 SSH · 只读查询
timeout 10s ros2 service call /speech_control speech_msgs/srv/SpeechControl "{request_type: 1, enable: false, mode: 0}"
timeout 10s ros2 service call /speech_control speech_msgs/srv/SpeechControl "{request_type: 5, enable: false, mode: 0}"
需要时：开启本地识别（修改语音策略）

先协调现场应用。使用中性测试语句，避免“站起、跟我走”等可能触发原厂动作的指令。连续识别不保证跳过所有唤醒条件。

机器狗 SSH · 设置并复查
timeout 10s ros2 service call /speech_control speech_msgs/srv/SpeechControl "{request_type: 3, enable: true, mode: 1}"
timeout 10s ros2 service call /speech_control speech_msgs/srv/SpeechControl "{request_type: 1, enable: false, mode: 0}"
机器狗 SSH · 先监听，再按设备交互方式讲话
timeout 30s ros2 topic echo /speech/asr_result aorta_msgs/msg/AsrResult --no-daemon --once

验收：实际收到 text。provider 1 为本体麦克风，2 为 UWB；未知来源不能自行归类。征得参与者同意后测试。

有开关、没文字
机器狗 SSH · 输入帧率
timeout 8s ros2 topic hz /raw_audio_dump --window 20

有音频帧不代表成功唤醒或 ASR 成功。检查交互方式与策略；云端模式还要确认设备外网和云服务配置。

05 / 5 MIN

把能力接入 Guide Bot

感知 / 转写 → 应用判断 → 展示或受控动作 → 结果验证

检测、ASR、Dify 意图解析、导航是不同环节。SSH 成功不等于看板已接通全部能力。

演示问题验证依据
看到人了吗？新鲜 person 检测框
听懂了吗？实际 text 与后续意图解析结果
找空位为何没执行？核对当前部署；此前代码仅识别该意图，未完整执行
到达目标了吗？完成反馈，不能只看服务接纳

讲师收束：“今天拿到的最小证据，是一条真实识别结果。下一步把它接到应用。”
